# Kritika Gupta | Business Analyst Portfolio

Live site: [https://kritikagupta26.github.io](https://kritikagupta26.github.io)

## Overview

This repository contains Kritika Gupta's professional Business Analyst portfolio. It presents transferable capability across requirements discovery, process transformation, stakeholder management, delivery governance, testing, workflow automation and data-led decision support.

## Portfolio coverage

- Business analysis capabilities and operating approach
- Anonymised case studies with challenge, action and impact
- Career journey, recognition, education and technology toolkit
- Contact links for professional opportunities

## Confidentiality

The case studies are intentionally anonymised. The website does not publish client data, proprietary dashboards, source files, credentials or confidential company information.

## Files

- `index.html`: Website content and structure
- `styles.css`: Responsive design and visual styling
- `script.js`: Case-study and scroll interactions
- `.nojekyll`: Ensures direct static-file publishing on GitHub Pages

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository named exactly `KritikaGupta26.github.io`.
2. Extract the downloaded ZIP on your computer.
3. Upload the files **inside** the extracted `KritikaGupta26.github.io` folder. Do not upload the enclosing folder itself.
4. Confirm that `index.html` appears at the repository root.
5. Open **Settings**, then **Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select the `main` branch and `/ (root)`, then click **Save**.
8. Wait a few minutes, then visit [https://kritikagupta26.github.io](https://kritikagupta26.github.io).

## Updating the portfolio

Edit the relevant file directly in GitHub or upload a revised version with the same filename. GitHub Pages will redeploy automatically after the change is committed.
